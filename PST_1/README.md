When running the program, a menu with 5 options will be presented. 
Option 1, "Register New Student", will prompt the user for the student's name and enrolment, and add them to the student database. 
Option 2, "Enrol Existing Student", will prompt the user for an existing student's ID and new enrolment, then add that instrument to the student if found.
Option 3, "Lookup Student or Teacher", will prompt the user for a search term. The term will be case insensitively matched against every name in the student database, and every name and speciality in the teacher database. The found matches will then be presented to the user.
Option 4, "List all Students", will list the id, name and enrolments of every student in the database.
Option 5, "List all Teachers", will list the id, name and speciality of every teacher in the database.
Entering "q" (case insensitive) on the main menu will exit the program.
