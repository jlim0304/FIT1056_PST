Run the main.py file to start.  
When running the program, it will first check for a database "msms.json" file in the data folder to read from. If not found, it will create an empty default file to write to.  
A menu with 3 options will then be presented to the user.  
  
Option 1, "View daily roster" will prompt the user for the day and then print out lessons on the day, if any.  
Option 2, "Switch student course" will prompt the user for the student's id, and the new and old course ids, and then remove and add them to the courses respectively.  
Option 3, "Check in student" will prompt the user for the student's id and the course id, then check the student into the course.  

Entering "q" (case insensitive) on the main menu will exit the program.
