When running the program, it will first check for a database "msms.json" file to read from. If not found, it will create an empty default file to write to.  
A menu with 8 options will then be presented to the user.  
  
Option 1, "Check-in Student" will prompt the user for the student's id and course id, and save the attendance record to file.  
Option 2, "Print Student Card" will prompt the user for the student's id, and "print" their id, name, and enrollments to a new file.  
Option 3, "Add Teacher" will prompt the user for the teacher's name and speciality, and save the details to file.  
Option 4, "Add Student" will prompt the user for the student's name and enrollments, and save the details to file.  
Option 5, "Update Teacher Info" will prompt the user for the teacher's id and field, and update the details in the file.  
Option 6, "Update Student Info" will prompt the user for the student's id and field, and update the details in the file.  
Option 7, "Remove Teacher" will prompt the user for the teacher's id, and delete the teacher's info from the file. The ID number is not returned.  
Option 8, "Remove Student" will prompt the user for the student's id, and delete the student's info from the file. The ID number is not returned.  
Entering "q" (case insensitive) on the main menu will exit the program.
